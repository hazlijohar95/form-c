# CONTEXT.md — Form C Studio domain glossary

- **Engagement** — one client × YA; carries SME profile, PBT, all schedules.
- **Adjusted income** — net profit + sectioned add-backs − credits − double deductions.
- **Schedule 3** — capital allowances computation (CA, BC, BA, residual expenditure).
- **SME** — SME qualification (5 conditions) driving rate bands and Para 19A cap.
- **Disallowance** — WHT s.39(2), earnings stripping s.140C, deemed interest s.140B synthesis.
- **Computation bridge** — UI Engagement → FormCInput mapping + memoised compute.
- **MyTax export** — JSON shaped to match skill/formc-mytax field map.
- **Chargeable income** — statutory → aggregate → chargeable pipeline owning caps, FIFO loss expiry, bands, and its own findings.
